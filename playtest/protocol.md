# External Playtest Protocol

เอกสารนี้สำหรับ moderator เท่านั้น ห้ามอธิบายปุ่มหรือเฉลยก่อนเริ่ม ยกเว้นผู้เล่นติดจนเล่นต่อไม่ได้

## ก่อนเริ่ม

- ใช้ build และ commit เดียวกันกับผู้ทดสอบทุกคน
- ขออนุญาตบันทึกหน้าจอ/เสียงก่อนเริ่ม หากต้องการบันทึก
- เตรียมกระดาษหรือแบบฟอร์มจดเวลา โดยไม่ให้ผู้เล่นเห็น checklist นี้
- ให้ผู้เล่นนั่งในสภาพแวดล้อมปกติ ใช้เมาส์และคีย์บอร์ดที่คุ้นเคย
- บันทึกว่าผู้เล่นเลือกภาษาไทยหรือ English; ห้ามชี้นำให้เลือกภาษาใดภาษาหนึ่ง

### สิ่งที่ moderator ต้องรู้ก่อน แต่ห้ามบอกผู้เล่น

**คืนแรกเหมือนกันทุกคน และเป็นคืนที่ง่ายผิดปกติ** ทุก build เริ่มที่ seed เดียวกัน
(`481516`) ซึ่งจากการวัด 15 คืน คืนนี้อยู่สุดขอบบนทุกด้าน: เบาะแส 63 ชิ้น (คืนอื่น 16–54),
คำให้การ 12 รายการ และมีเหตุการณ์ที่เป็นไปไม่ได้เกิดต่อหน้าผู้เล่นถึง 3 ครั้ง ซึ่งแต่ละครั้ง
แทบจะชี้ตัวคำตอบให้ตรง ๆ **อย่าสรุปจากคืนแรกเพียงคืนเดียวว่าเกมให้ข้อมูลพอ**
ถ้าเวลาอำนวย ให้ผู้เล่นกด `เล่นกะคืนนี้ใหม่` อีกหนึ่งรอบ ซึ่งจะได้ seed ใหม่และคดีใหม่
แล้วบันทึกแยกกันสองรอบ

**มีสองแบบคืนที่ต่างกันมาก** ราวหนึ่งในหกคืน ตัวละครที่ผู้เล่นขับเองคือคนที่ถูกบงการ
คืนแบบนั้นจะจบด้วยการที่ทั้งโรงแรมเดินมาล้อมผู้เล่นก่อนรุ่งเช้า ไม่ได้จบด้วยการกล่าวหา
ถ้าเจอคืนแบบนี้ ให้บันทึกว่าผู้เล่นเข้าใจไหมว่าเกิดอะไรขึ้น **ห้ามบอกล่วงหน้าว่ามีคืนแบบนี้อยู่**

**ห้ามพูดคำว่า "กล่าวหาตัวเอง"** การค้นพบว่าเอ่ยชื่อตัวเองได้คือส่วนหนึ่งของเกม
ให้บันทึกแทนว่าผู้เล่นเห็นตัวเลือกนั้นไหม และคิดอย่างไรกับมัน

## สคริปต์ moderator

อ่านข้อความนี้เท่านั้น:

> คุณเป็น George พนักงานต้อนรับกะกลางคืน มีเหตุการณ์ผิดปกติเกิดขึ้นในโรงแรม ลองสำรวจและตัดสินใจว่าควรเชื่อใคร

จากนั้นเงียบและสังเกต ห้ามบอกลำดับการเล่นหรือชื่อปุ่มจนกว่าจะติดเกิน 60 วินาที

## สิ่งที่ต้องบันทึก

### เริ่มเล่นเป็นไหม

| Metric | วิธีวัด |
|---|---|
| First action | เวลาจากเปิดเกมถึง action แรก |
| Onboarding comprehension | ผู้เล่นอธิบายลูป เดิน → สังเกต → เปรียบเทียบ → ตัดสินใจ ได้หรือไม่ |
| First move | เวลาถึงการย้ายห้องครั้งแรก |
| First investigation | เวลาถึง Talk/Inspect ครั้งแรก |
| Case-file discovery | ผู้เล่นหาแฟ้มคดีและเปลี่ยนหน้าเบาะแสเองหรือไม่ |
| Follow comprehension | ผู้เล่นเข้าใจว่า Follow ทำอะไรหรือไม่ |
| Help count | จำนวนครั้งที่ moderator ต้องช่วย |
| Blockers | จุดที่เล่นต่อไม่ได้ |

### อ่านข้อมูลออกไหม

| Metric | วิธีวัด |
|---|---|
| Evidence comprehension | อธิบาย source/confidence ได้หรือไม่ |
| Clue readability | ผู้เล่นอ่านหนึ่ง clue แล้วบอกได้ทันทีว่าใคร ทำอะไร ที่ไหน และรู้จากใคร |
| Insight lens | ผู้เล่นเข้าใจว่าเจตนาของ NPC เป็นการอนุมาน ไม่ใช่ข้อเท็จจริงหรือไม่ |
| UI readability | มีข้อความล้น/ทับกัน หรือหาปุ่มไม่เจอหรือไม่ |
| Language comprehension | ภาษาไทยช่วยให้เข้าใจขึ้นหรือมีคำแปลที่สะดุดหรือไม่ |

### คำให้การและการจับโกหก

| Metric | วิธีวัด |
|---|---|
| Asks for an account | ผู้เล่นขอให้ใครสักคนเล่าว่าไปไหนมาเองหรือไม่ ครั้งแรกกี่นาที |
| Statements page found | ผู้เล่นหาหน้าคำให้การเจอเองหรือไม่ (แยกจากหน้าเบาะแส) |
| Statement vs clue | ผู้เล่นเข้าใจไหมว่าคำให้การคือ "สิ่งที่มีคนพูด" ไม่ใช่ "สิ่งที่เกิดขึ้น" |
| Contradiction used | ผู้เล่นเอาข้อขัดแย้งไปกดใครสักคนหรือไม่ และเข้าใจผลลัพธ์หรือไม่ |
| Contradiction available | จบคืนมีข้อขัดแย้งค้างที่จับได้แต่ไม่ถูกใช้กี่ข้อ |

### ผู้เล่นรู้ตัวไหมว่าตัวเองก็ถูกมอง

| Metric | วิธีวัด |
|---|---|
| Badge noticed | ผู้เล่นสังเกตเห็นป้ายข้างนาฬิกาตอนมันขึ้นหรือไม่ ถามหลังเล่นว่าเห็นอะไรบ้าง |
| Badge understood | ผู้เล่นเข้าใจไหมว่ามันคือความสงสัยที่คนอื่นมีต่อ **ตัวเอง** ไม่ใช่ต่อผู้ต้องสงสัย |
| Behaviour changed | เห็นป้ายแล้วเปลี่ยนพฤติกรรมไหม (กลับไปเคาน์เตอร์ ลดการเดิน เลิกงัดของ) |
| Exposure page found | ผู้เล่นเปิดหน้า "ใครกำลังมองคุณอยู่" เองหรือไม่ |

### ตอนโรงแรมลงมือ (บันทึกเฉพาะคืนที่เกิดขึ้น)

| Metric | วิธีวัด |
|---|---|
| Saw it coming | ผู้เล่นรู้ตัวก่อนไหมว่ากำลังจะถูกล้อม หรือรู้สึกว่าโผล่มาเฉย ๆ |
| Countdown read | นับถอยหลัง 45 นาทีสุดท้ายอ่านออกว่าเป็นภัยคุกคามหรือไม่ |
| Choice taken | เลือกอะไรระหว่างสารภาพ / ปฏิเสธ / หนี และเพราะอะไร |
| Made sense | ผู้เล่นอธิบายได้ไหมว่าทำไมโรงแรมถึงมาล้อมตัวเอง |

### ตอนจบ

| Metric | วิธีวัด |
|---|---|
| Ending reached | ได้ฉากจบแบบไหน (กล่าวหาถูก / กล่าวหาผิด / เอ่ยชื่อตัวเอง / ถูกล้อมจับ) |
| Ending clarity | ผู้เล่นอธิบายเหตุผลที่ได้ฉากจบนั้นได้หรือไม่ |
| Self-accusation seen | ผู้เล่นเห็นตัวเลือกเอ่ยชื่อตัวเองไหม และคิดยังไงกับมัน |
| Twist landed | ถ้าเป็นคืนที่ผู้เล่นคือคำตอบ: รู้สึกว่ามีเบาะแสมาก่อน หรือรู้สึกว่าเกมโกง |
| Hypothesis | ผู้เล่นสงสัยใครและเหตุผลอะไร เปลี่ยนใจกี่ครั้งระหว่างคืน |
| **What decided it** | **ผู้เล่นตัดสินใจจากอะไร — เบาะแสที่สะสมมา หรือเหตุการณ์ที่เป็นไปไม่ได้ที่เห็นกับตา** |
| Time pressure | ผู้เล่นรับรู้ว่าเวลาเดินต่อ และรู้ว่าต้องสรุปคดีก่อนรุ่งเช้าหรือไม่ |
| Surprise response | เหตุการณ์ไฟกะพริบ/สายปริศนา/กุญแจหายเปลี่ยนเส้นทางหรือสมมติฐานหรือไม่ |

> บรรทัด **What decided it** สำคัญที่สุดในตารางนี้ จากการวัดภายใน คืนที่ผู้เล่นเห็น
> เหตุการณ์ที่เป็นไปไม่ได้ตอบถูก 6 จาก 6 ส่วนคืนที่ไม่เห็นตอบถูก 1 จาก 7 ซึ่งเท่ากับ
> การเดาสุ่ม ถ้าผู้เล่นจริงตอบเหมือนกัน แปลว่าเบาะแสที่เหลือยังไม่ได้ทำงาน

## เกณฑ์ผ่านเบื้องต้น

พื้นฐาน:

- ผู้เล่น 4 จาก 5 คนย้ายห้องได้โดยไม่ต้องบอกวิธี
- ผู้เล่น 4 จาก 5 คนคลิกตัวละครเพื่อคุย/ติดตาม หรือใช้ `สำรวจห้อง` ได้เอง
- ผู้เล่น 4 จาก 5 คนเข้าใจคำแนะนำ `ทำอะไรต่อ` และเปิดแฟ้มคดีได้เอง
- ผู้เล่น 4 จาก 5 คนเข้าสู่การสรุปคดีและอธิบายเหตุผลเลือกผู้ต้องสงสัยได้
- ผู้เล่น 3 จาก 5 คนอธิบายได้ว่า evidence เป็นข้อมูลที่มีความน่าเชื่อถือ ไม่ใช่ truth ที่สมบูรณ์
- ไม่มี blocker ระดับเปิดเกมไม่ได้หรือเล่นต่อไม่ได้

ลูปที่เพิ่งต่อเข้ามา:

- ผู้เล่น 3 จาก 5 คนขอให้ใครสักคนเล่าว่าไปไหนมา โดยไม่ต้องมีคนบอก
- ไม่มีใครเข้าใจว่าคำให้การคือข้อเท็จจริงที่ยืนยันแล้ว
- ผู้เล่น 3 จาก 5 คนสังเกตเห็นป้ายความสงสัยที่มีต่อตัวเอง และอย่างน้อย 2 คนเข้าใจว่ามันหมายถึงอะไร
- ผู้เล่น 4 จาก 5 คนอธิบายได้ว่าทำไมถึงได้ฉากจบที่ได้
- คืนที่โรงแรมลงมือ: ไม่มีใครรู้สึกว่ามันโผล่มาโดยไม่มีสัญญาณ

## หลังเล่น

ให้ผู้เล่นกรอก `feedback-template.md` โดยไม่ชี้นำคำตอบ จากนั้นถามเพิ่มเพียง:

1. จุดไหนทำให้สับสนที่สุด
2. บทพูดประโยคไหนไม่เป็นธรรมชาติ
3. คุณคิดว่าควรทำอะไรต่อ แต่เกมไม่ได้บอกหรือไม่
4. ถ้าปรับได้หนึ่งอย่าง คุณจะปรับอะไร
5. อ่านเบาะแสหนึ่งใบให้ฟัง แล้วอธิบายว่าข้อมูลนี้มาจากใครและเชื่อได้แค่ไหน
6. ตอนที่คุณเลือกชื่อสุดท้าย คุณตัดสินจากอะไร เล่าให้ฟังทีละขั้น
7. ระหว่างคืน มีจังหวะไหนที่รู้สึกว่าตัวเองกำลังถูกจับตาบ้างไหม

จัดปัญหาเป็น `blocker`, `readability`, `pacing`, `wording` หรือ `cosmetic` ก่อนตัดสินใจแก้
