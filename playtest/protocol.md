# External Playtest Protocol

เอกสารนี้สำหรับ moderator เท่านั้น ห้ามอธิบายปุ่มหรือเฉลยก่อนเริ่ม ยกเว้นผู้เล่นติดจนเล่นต่อไม่ได้

## ก่อนเริ่ม

- ใช้ build และ commit เดียวกันกับผู้ทดสอบทุกคน
- ขออนุญาตบันทึกหน้าจอ/เสียงก่อนเริ่ม หากต้องการบันทึก
- เตรียมกระดาษหรือแบบฟอร์มจดเวลา โดยไม่ให้ผู้เล่นเห็น checklist นี้
- ให้ผู้เล่นนั่งในสภาพแวดล้อมปกติ ใช้เมาส์และคีย์บอร์ดที่คุ้นเคย
- บันทึกว่าผู้เล่นเลือกภาษาไทยหรือ English; ห้ามชี้นำให้เลือกภาษาใดภาษาหนึ่ง

## สคริปต์ moderator

อ่านข้อความนี้เท่านั้น:

> คุณเป็น George พนักงานต้อนรับกะกลางคืน มีเหตุการณ์ผิดปกติเกิดขึ้นในโรงแรม ลองสำรวจและตัดสินใจว่าควรเชื่อใคร

จากนั้นเงียบและสังเกต ห้ามบอกลำดับการเล่นหรือชื่อปุ่มจนกว่าจะติดเกิน 60 วินาที

## สิ่งที่ต้องบันทึก

| Metric | วิธีวัด |
|---|---|
| First action | เวลาจากเปิดเกมถึง action แรก |
| Onboarding comprehension | ผู้เล่นอธิบายลูป เดิน → สังเกต → เปรียบเทียบ → ตัดสินใจ ได้หรือไม่ |
| First move | เวลาถึงการย้ายห้องครั้งแรก |
| First investigation | เวลาถึง Talk/Inspect ครั้งแรก |
| Case-file discovery | ผู้เล่นหาแฟ้มคดีและเปลี่ยนหน้าเบาะแสเองหรือไม่ |
| Follow comprehension | ผู้เล่นเข้าใจว่า Follow ทำอะไรหรือไม่ |
| Evidence comprehension | อธิบาย source/confidence ได้หรือไม่ |
| Help count | จำนวนครั้งที่ moderator ต้องช่วย |
| Blockers | จุดที่เล่นต่อไม่ได้ |
| Hypothesis | ผู้เล่นสงสัยใครและเหตุผลอะไร |
| UI readability | มีข้อความล้น/ทับกัน หรือหาปุ่มไม่เจอหรือไม่ |
| Language comprehension | ภาษาไทยช่วยให้เข้าใจขึ้นหรือมีคำแปลที่สะดุดหรือไม่ |
| Time pressure | ผู้เล่นรับรู้ว่าเวลาเดินต่อ และรู้ว่าต้องสรุปคดีก่อนรุ่งเช้าหรือไม่ |
| Insight lens | ผู้เล่นเข้าใจว่าเจตนาของ NPC เป็นการอนุมาน ไม่ใช่ข้อเท็จจริงหรือไม่ |
| Surprise response | เหตุการณ์ไฟกะพริบ/สายปริศนา/กุญแจหายเปลี่ยนเส้นทางหรือสมมติฐานหรือไม่ |
| Ending clarity | ผู้เล่นเข้าใจเหตุผลที่ชนะหรือแพ้หลังสรุปคดีหรือไม่ |
| Clue readability | ผู้เล่นอ่านหนึ่ง clue แล้วบอกได้ทันทีว่าใคร ทำอะไร ที่ไหน และรู้จากใครหรือไม่ |

## เกณฑ์ผ่านเบื้องต้น

- ผู้เล่น 4 จาก 5 คนย้ายห้องได้โดยไม่ต้องบอกวิธี
- ผู้เล่น 4 จาก 5 คนคลิกตัวละครเพื่อคุย/ติดตาม หรือใช้ `สำรวจห้อง` ได้เอง
- ผู้เล่น 4 จาก 5 คนเข้าใจคำแนะนำ `ทำอะไรต่อ` และเปิดแฟ้มคดีได้เอง
- ผู้เล่น 4 จาก 5 คนเข้าสู่การสรุปคดีและอธิบายเหตุผลเลือกผู้ต้องสงสัยได้
- ผู้เล่น 3 จาก 5 คนอธิบายได้ว่า evidence เป็นข้อมูลที่มีความน่าเชื่อถือ ไม่ใช่ truth ที่สมบูรณ์
- ไม่มี blocker ระดับเปิดเกมไม่ได้หรือเล่นต่อไม่ได้

## หลังเล่น

ให้ผู้เล่นกรอก `feedback-template.md` โดยไม่ชี้นำคำตอบ จากนั้นถามเพิ่มเพียง:

1. จุดไหนทำให้สับสนที่สุด
2. บทพูดประโยคไหนไม่เป็นธรรมชาติ
3. คุณคิดว่าควรทำอะไรต่อ แต่เกมไม่ได้บอกหรือไม่
4. ถ้าปรับได้หนึ่งอย่าง คุณจะปรับอะไร
5. อ่านเบาะแสหนึ่งใบให้ฟัง แล้วอธิบายว่าข้อมูลนี้มาจากใครและเชื่อได้แค่ไหน

จัดปัญหาเป็น `blocker`, `readability`, `pacing`, `wording` หรือ `cosmetic` ก่อนตัดสินใจแก้
