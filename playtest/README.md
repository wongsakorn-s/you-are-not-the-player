# YOU ARE NOT THE PLAYER — First Fun Playtest

นี่คือ build ทดลองระยะแรกของเกมแนว Psychological Social Deduction Mystery ใช้เวลาประมาณ 10–15 นาที

## วิธีเริ่ม

1. แตกไฟล์ zip ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
2. เปิด `YOU ARE NOT THE PLAYER.exe`
3. กด `ตั้งค่า` หากต้องการเปลี่ยนภาษาไทย/English หรือขนาดตัวอักษร
4. กด `เริ่มคดีใหม่` อ่านเป้าหมายและวิธีอ่านเบาะแสสั้น ๆ
5. กด `เริ่มกะกลางคืน` แล้วเล่นโดยไม่ต้องอ่านเอกสารอื่นก่อน

การควบคุมใช้เมาส์ทั้งหมด: คลิกห้องเพื่อย้าย และคลิกจุดตัวละครในห้องเดียวกันเพื่อเลือก `คุย`, `ติดตาม` หรือ `ถามด้วยเบาะแส` แผงด้านขวามีคำสั่งหลักเพียง `สำรวจห้อง`, `เปิดแฟ้มคดี` และ `กล่าวหาผู้ต้องสงสัย` ส่วนปุ่ม `เมนู` ใช้พักเกม ตั้งค่า หรือออกจากเกม

หลังเริ่มสืบสวน เวลาและกิจวัตรของ NPC จะเดินต่อแม้กำลังอ่านหรือสนทนา กด `ดูเจตนา` เพื่อดูสิ่งที่ George คาดว่าแต่ละคนกำลังทำ แต่ข้อมูลนี้อาจไม่ใช่ความจริง

## วิธีอ่านเบาะแส

เกมไม่ใช้รหัส `T...` หรือคะแนนระบบแล้ว เบาะแสจะแสดงเป็นภาษาปกติ เช่น:

```text
[23:15] แอนนาเข้าไปในชั้นใต้ดิน
จอร์จเห็นด้วยตัวเอง • น่าเชื่อถือมาก
```

- เวลาในวงเล็บคือเวลาที่เกิดเหตุ
- ประโยคหลักบอกว่าใครทำอะไรและที่ไหน
- บรรทัดล่างบอกว่าจอร์จเห็นเองหรือได้ยินจากใคร
- `ควรจับตา` และ `น่าสงสัยมาก` เป็นข้อสรุปเบื้องต้น ไม่ใช่คำเฉลย

## เป้าหมายการทดลอง

คุณรับบทเป็นจอร์จ พนักงานต้อนรับกะกลางคืน เป้าหมายคือสำรวจโรงแรมและหาว่าใครกำลังถูก “ผู้ควบคุม” บงการอยู่

ลองทำสิ่งต่อไปนี้ตามลำดับที่คุณคิดว่าเหมาะสม:

- ย้ายไปห้องอื่นอย่างน้อยหนึ่งห้อง
- คุยกับตัวละครอย่างน้อยสองคน
- คลิกตัวละครและใช้ `ติดตาม` กับตัวละครหนึ่งคน
- ตรวจสอบวัตถุหนึ่งชิ้น
- เปิด `แฟ้มคดี` พลิกดูเบาะแส และลองเปลี่ยนมุมมองหนึ่งแบบ
- คลิกตัวละครแล้วเลือก `ถามด้วยเบาะแส`
- กด `กล่าวหาผู้ต้องสงสัย` และเลือกคนที่คิดว่าถูกผู้ควบคุมบงการก่อนรุ่งเช้า

## คำแนะนำ

- คดีมีคำตอบถูก/ผิด แต่เป้าหมายของ playtest คือดูว่าข้อมูลช่วยให้คุณตั้งสมมติฐานและตัดสินใจได้หรือไม่ ไม่จำเป็นต้องพยายามเล่นให้สมบูรณ์แบบ
- ระหว่างกะจะมีเหตุการณ์แทรกซึ่งเกิดตาม seed เดิมซ้ำได้ กรุณาบันทึกว่าเหตุการณ์ใดเปลี่ยนสมมติฐานของคุณ
- หากติดขัด ให้ลองจดว่าคุณคาดหวังให้ปุ่มหรือข้อมูลอยู่ตรงไหนก่อนขอความช่วยเหลือ
- ปิดเกมด้วยการปิดหน้าต่างตามปกติ

หลังเล่นเสร็จ กรุณากรอก `feedback-template.md` และส่งกลับพร้อม `build-info.txt`
